# RawLab 编辑功能模块全面升级规格（v0.7–v0.9）

版本：2.0（完整规格版，替代 2026-10-15 初版规划）
基线：release v0.6.3（Android 补丁版，编辑功能集与 v0.6.0 四端一致；代码事实已逐项核实）
对标对象：国内主流修图/胶片类应用的通用能力集（醒图、美图秀秀、泼辣修图、FIMO/Dazz 类胶片应用、Lightroom 移动版），按通用能力描述，不逐款引用具体参数
状态字段约定：`[TBD]` 待决策；`[Assumption]` 推断条件，实现前需验证

---

## 1. 背景与目标

v0.6.3 编辑器已具备专业 RAW 显影主干：14 款大师配方、8 通道 HSL（24 值）、小波降噪
（亮度/色度/粗色度）、暗角/颗粒（8 参数）、批量导出、每张照片编辑记忆、三种曝光基准。

与国内同类应用对照，缺口集中在三类：

1. 专业编辑器标配缺失：裁剪/旋转/水平矫正、多点曲线、白平衡吸管、撤销/重做栈、对比原图。
2. 国内流行交互缺失：社交比例预设、配方导入导出与二维码分享、胶片日期水印、强度分屏对比。
3. 进阶调色能力缺失：色彩分级三色轮、局部渐变调整。

目标：三期补齐，全程保持 macOS / iOS / Android / Windows 四端同参数同结果；
旧编辑记录与批量快照向后兼容（新增参数读旧记录时取默认值，行为不变）。

## 4. 产品原则与定位

- 定位声明：专业 RAW 显影 + 胶片模拟。所有升级必须服务"更准的显影、更强的调色、更顺的出片"。
- 明确不做：人像美颜瘦脸、贴纸、拼图、图文排版、社区信息流。与定位冲突且维护成本高；
  若后续留存数据支持，另行立项评审。
- 兼容原则：原始文件永不改写；所有编辑只落在编辑记忆与导出物。
- 一致性原则：同一参数在四端的名称、范围、默认值、步进、渲染结果完全一致。

### 5.2 调整管线（最终顺序）

```
几何域：EXIF 方向 → 裁剪/旋转/矫正(FR-01)
显影域：RAW 显影(曝光基准) → 白平衡(camera/custom/吸管) → 曝光 → 高光/阴影/对比
        → 曲线(FR-02, 替换原 S 曲线节点) → 饱和 → HSL(8通道)
        → 色彩分级(FR-07) → 局部蒙版(FR-11)
细节域：RAW 降噪 → 小波降噪 → 显示色度降噪 → 锐化
效果域：暗角 → 颗粒 → 水印/边框(FR-09, 仅导出栅格化)
输出域：导出尺寸 → 元数据(EXIF 强度标注等)
```

规则：
- 分级与蒙版强度为 0 时跳过该节点，避免 GPU 无谓开销（沿用 displayChromaDenoise 的 didSet 捷径模式）。
- 局部蒙版为增量应用节点：不重复施加全局参数，仅按蒙版权重叠加各蒙版自身携带的参数增量（见 7.11）。
- 水印不进预览渲染管线主路径，预览仅叠加显示层（可关），导出时栅格化。

### 5.3 编辑记忆与版本迁移

- 编辑记忆 JSON 增加 `schemaVersion` 整数字段；读入时按迁移表逐级升档，写出永远写最新版。
- 迁移规则只有两条：旧记录缺失字段取"新增字段表"的默认值；被替代字段（toneCurve → curve.luma）
  按 7.2 的映射函数一次性转换，转换后保留原字段两个大版本以防回滚。

## 7. 功能需求（完整规格）

### 7.1 FR-01 裁剪与几何矫正（P0，v0.7.0）

**目的**：补齐编辑器第一刚需；无裁剪的 RAW 编辑器在国内对比下属于明显体验残缺。

**入口与布局（四端）**

| 端 | 入口 | 布局 |
|---|---|---|
| macOS | 画布上方工具栏"裁剪"按钮（新增，与缩放控件同级） | 裁剪模式覆盖画布，右侧出现比例/旋转条 |
| iOS | 底部工具条新增"裁剪"图标 | 全屏裁剪视图，底部比例条横滑 |
| Android | 编辑页页签新增"裁剪"（页签列表由 16 项增至 17 项，改为可横滑分页，见 8.4） | 画布裁剪框 + 底部比例条 |
| Windows | 右侧调整面板顶部工具行新增"裁剪" | 画布覆盖裁剪框 + 面板比例/角度区 |

**比例预设**：自由、原比例、1:1、4:3、3:4、16:9、9:16、3:2、2:3。
9:16 / 3:4 面向小红书与朋友圈发布场景；顺序固定如上，四端一致。

**处理规则**
1. EXIF 方向最先应用，裁剪框坐标定义在"方向校正后"的显示坐标系。
2. 旋转整体 ±45°、步进 0.1°；水平矫正：用户沿画面参照线划线，取该线与水平夹角写入
   straightenAngle（±15°），等效于反方向旋转，两者叠加后总角度仍受 ±45° 限制，超限时按比例截断并提示。
3. 裁剪框最小面积 = 方向校正后画面的 5%；小于该值时"应用"按钮禁用。
4. 归一化存储（crop.rect 相对画面），导出尺寸变化时裁剪框语义不变。
5. 直方图、高光/阴影裁切提示按裁剪区域重算；重算复用现有直方图通路。
6. 裁剪不参与像素级显影计算，仅在取景与输出环节生效——保证 5.2 的"默认参数逐像素一致"出口标准不受影响。

**状态**：idle → editing（进入裁剪模式）→ applied（写入 crop.*）；editing 中"取消"回滚到入模式前快照。
applied 后提供独立"重置裁剪"（不与整体重置混用）。

**异常**：打开无 EXIF 方向的文件按 1 处理；批量"应用当前设置到文件夹"包含 crop.*。

**验证要点**：四端同 crop.rect + rotation 输出像素一致；比例锁定拖拽四端手感一致（数值约束一致即可）。

### 7.2 FR-02 多点色调曲线（P0，v0.7.0）

**目的**：把单值 S 曲线升级为专业曲线，是"泼辣/LR 类"用户判断工具专业度的首要信号。

**行为**
- 主曲线（亮度）+ R/G/B 三条通道曲线；每条 ≤10 个控制点，端点 (0,0)、(1,1) 可纵向移动、不可删除。
- 点击加点、拖动改形、双击删点；拖动时显示该点输入/输出数值（0–255 显示，内部归一化存储）。
- 预设四款：neutral（单位直线）、midContrast、strongContrast、filmS（肩部压缩 + 趾部抬升的胶片形）。
  预设写入控制点而非运行时参数，写入后可继续手调。

**插值规则**：控制点间单调三次插值（monotone cubic），保证不产生过冲伪影；通道曲线作用于
显影域线性输出之后、饱和之前（管线位置替换原 S 曲线节点）。

**旧值迁移**：旧 `toneCurve = t ∈ [-1,1]` 一次性转换为主曲线三点 (0,0)、(0.5, 0.5 + 0.25t)、(1,1)。
该映射是单调递增的线性变换，四端实现一致即可；端点斜率由插值器自动求出。
`[Assumption]` 0.25 为视觉近似系数，实现时以"旧值 1.0 与旧版渲染对比差异最小"校准一次。

**UI 兼容（四端）**：原 S 曲线入口由滑杆改为点击进入曲线编辑器——iOS `AdjustmentKind.toneCurve`
行为变更；Android `tone_curve` 页签与 macOS/Windows 调整行同步改为入口按钮。列表/页签上的
数值摘要统一显示为主曲线中点输出偏差：`(midY − 0.5) × 200`，范围 ±100、步进 1、0 表示中性。

**验证要点**：四端同曲线点集输出逐像素一致；旧记录迁移后与旧版渲染主观无跳变；10 点上限、端点保护生效。

### 7.3 FR-03 白平衡吸管（P0，v0.7.0）

**行为**
1. 色温模块标题行新增吸管按钮；激活后画布光标/触摸态变为取样器，点选完成、Esc/再点按钮取消。
2. 取样：以点选处为中心 5×5 区域，转换到线性 RGB 求均值；参与均值前剔除高光裁切像素
   （任一通道 ≥ 0.98）与高饱和像素（饱和度 ≥ 0.25）`[Assumption, TBD：阈值实测校准]`。
   取样计算固定在 CPU 端对当前预览帧执行，不依赖各 GPU 后端，保证四端取样结果同值。
3. 反解出的色温/色调写入 temperature/tint，wbMode 自动切到 custom；连续点选以最后一次为准。
4. 显示取样点标记 2 秒后淡出；wbPicker.lastSample 仅作回显，不参与持久化行为。

**异常**：剔除后有效样本 < 4 个 → 提示"请选择中性灰区域"，不改动任何值。

**验证要点**：灰卡样片点选后与 camera 模式直方图偏移方向一致；四端取样结果同值（核心实现收敛在共享引擎）。

### 7.4 FR-04 撤销 / 重做与编辑历史（P0，v0.7.0）

**模型**：字段级增量命令栈。命令 = {字段路径, before, after, 操作名, 时间戳}。

**规则**
1. 连续滑杆拖动合并为一步：拖动结束（松手）后才生成命令；同字段 500ms 内的连续松手合并 `[Assumption, TBD]`。
2. 栈深 50 步，超限丢弃最旧；undo/redo 指针双向移动，指针处新操作截断redo 分支。
3. 覆盖范围：基础调节、HSL、曲线、分级、WB、效果、裁剪（裁剪以"一次应用"为一步）。
   配方套用为一步（before = 套用前全量受影响字段，after = 套用后值）。
4. 切换照片清空当前栈；编辑记忆仍按照片保存最终态，与栈无关。
5. "查看修改内容"列表（对齐 Snapseed 交互习惯）：四端各设独立入口按钮（工具栏/页签行），
   按时间倒序显示操作名 + 参数摘要；点列表项 = 撤销到该步（截断其后）；列表项内"删除该步" =
   从栈中移除该命令并重放其后所有命令（before/after 不足以重放时降级为"撤销到该步"，此时给出提示）。
6. 桌面端快捷键 Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z；移动端提供工具栏按钮；批量任务运行中禁用并提示"批量进行中"。

**状态**：栈不持久化；重开 App 从编辑记忆恢复最终态、栈为空、redo 不可用。

**验证要点**：四端操作名与摘要文案一致（见 8.5 术语表）；50 步上限、合并规则、批量互斥各有一条测试。

### 7.5 FR-05 对比原图（P0，v0.7.0）

**行为**
- 移动端长按照片区域；桌面端按住对比按钮或空格键（macOS/Windows 一致）。
- 按住期间渲染"原片" = 当前曝光基准显影 + 无任何调整，但保持裁剪取景（便于对位）；左上角"原图"角标。
- 松开恢复当前编辑态，无动画残帧。

**规则**：原片渲染复用显影缓存通路（同 exposureMode 的 RAW 显影结果 + 关闭全部调整）；
首次按住无缓存时显示加载态，超时 2 秒给出"正在显影"提示 `[Assumption, TBD]`。
对比期间禁止调节操作（控件禁用态）。

### 7.6 FR-06 强度分屏对比（P1，v0.8.0）

强度滑杆拖动期间，画面显示左右分屏：左 = 原片（同 FR-05 定义），右 = 当前强度渲染，
分屏线默认居中可拖动；松手恢复整幅当前态。依赖 FR-05 的原片渲染通路，属于其交互扩展。
滑杆值为 0 或 200% 极值时分屏仍有意义（与原片一致/满强度），不做特殊分支。

### 7.7 FR-07 色彩分级（P1，v0.8.0）

**参数**（三组独立 + 全局）：

| 字段 | 范围 | 默认 | 说明 |
|---|---|---|---|
| shadow.hue / mid.hue / high.hue | [0,360) | 0 | 色相角，0=红 |
| shadow.strength / mid.strength / high.strength | 0–100 | 0 | 0 时不进渲染路径 |
| grade.balance | ±50 | 0 | 三区权重整体偏移（负=偏阴影，正=偏高光） |

**处理规则**
1. 染色以目标 hue 为中心的加权混色实现，权重曲线随 strength 线性缩放；三区按亮度区间划分，
   区间边界随 balance 移动。核心实现收敛在共享引擎，四后端（CPU/Metal/GLES/D3D11）同参数同结果。
2. 管线位置：HSL 之后、局部蒙版之前（见 5.2）。
3. 近灰衰减：沿用 0.6.0 HSL 灰部渐变的衰减规则，防止深灰区出现亮度斑点。
4. 三色轮 UI：轮盘选 hue、轮盘半径或独立滑杆选 strength；四端布局差异仅在外观，参数语义一致。

**状态**：进编辑记忆与批量快照；旧记录全 0。覆盖规则区分两条路径：内置大师配方套用**不覆盖**
分级（沿用"配方只覆盖指定项"规则）；`.rawlab-look` 配方文件可在 `replaces` 中显式声明覆盖分级，
由导入方自担——两处规则以本条为唯一权威定义。

**验证要点**：四端同参数逐像素一致（复用 0.6.0 跨后端回归方法）；strength=0 与关闭状态输出一致。

### 7.8 FR-08 配方 / Look 导入导出（P1，v0.8.0）

**文件格式 `.rawlab-look`**（JSON，UTF-8）：

```
{
  "type": "rawlab-look",
  "formatVersion": 1,
  "name": "…",
  "subtitle": "…",
  "settings": { lutID?, lutStrength 默认值, 曝光/高光/阴影/对比/饱和/色调,
                curvePreset + curve 点集, hsl 24 值, grade 全组,
                denoise?, photoEffects?, watermark? },
  "replaces": [套用时被覆盖的字段清单]
}
```

- `lutID` 引用内置配方时，接收端无该内置配方则报"配方缺失"并整体拒绝（不部分导入）。
- 引用用户自定义 `.cube` LUT 的 Look：v0.8 不打包 LUT 本体，接收端缺失时按上条拒绝；
  是否携带 LUT 本体列入开放问题（见第 11 节）。

**导出**：Look 管理菜单"导出配置" → 生成文件 + 可选二维码。
**二维码容量策略**：参数序列化压缩后 ≤ 2.4KB 时生成二维码；超限自动降级为仅文件分享并提示。
`[TBD：压缩编码与降级阈值实测]`
**导入**：首页/相册页"导入配方"，扫码或选文件；重名时弹"替换 / 另存"；导入成功入 Look 库，
命名规则与现有自定义 Look 一致。
**错误处理**：损坏、version 不识别、字段缺失 → 明确报错且不改库；formatVersion 高于当前版按"请升级应用"提示。

**验证要点**：四端导出的文件互相导入结果一致；拒绝路径各一条测试。

### 7.9 FR-09 胶片日期水印与边框（P1，v0.8.0）

| 字段 | 取值 | 默认 |
|---|---|---|
| watermark.style | off / stampA / stampB / stampC（三款经典橙字日期戳字体样式） | off |
| watermark.frame | off / thin / rounded | off |

**规则**
1. 时间取值链：EXIF DateTimeOriginal → 文件修改时间；显示格式 `YYMMDD.HHMM`（经典胶片习惯）。
2. 位置固定右下，内边距 = 2% 输出长边；字号 = 2.2% 输出长边 `[Assumption, TBD]`；
   随导出尺寸等比缩放，同一设置在原图与 2048 长边导出中视觉占比一致。
3. 仅作用于导出物：预览默认显示可关（叠加显示层），任何路径不写原始文件。
4. 进编辑记忆与批量快照；批量按各照片参数渲染。

### 7.11 FR-11 局部调整（P1 前半 / P2 后半）

**v0.8.0 交付：几何渐变蒙版**

| 蒙版类型 | 参数 |
|---|---|
| 径向 | 中心 (cx,cy)、半径 r、羽化 feather、反转 invert（均归一化坐标，定义在裁剪后画面） |
| 线性 | 起止点 (x1,y1)-(x2,y2)、羽化、反转 |

- 作用参数子集：曝光、对比、色温、饱和、分级强度（五类）`[TBD：是否纳入锐化]`。
  每个蒙版携带自己的参数增量 delta（同参数单位与全局调节一致），**不与全局调节叠加冲突**：
  全局管线照常应用，蒙版节点在管线末端单遍叠加增量——`result = base + Σ wᵢ × deltaᵢ`
  （i 遍历命中的蒙版，wᵢ 为该蒙版在该像素的权重）。
- 权重 w ∈ [0,1]（羽化带内线性过渡）；CPU 参考实现 + 三 GPU 后端同步实现（与 FR-07 同批设计管线插槽）。
- 蒙版数量上限 5 个/照片 `[Assumption, TBD]`；蒙版编辑入撤销栈的粒度 = 一次编辑会话
  （进入蒙版编辑到确认/退出）为一步，与裁剪同口径。

**P2 评估：AI 主体/天空蒙版**——进入 FR-10 同一批预研，先回答端侧模型内存/耗时口径。

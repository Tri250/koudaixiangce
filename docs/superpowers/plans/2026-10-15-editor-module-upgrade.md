# RawLab 编辑功能模块升级规划（v0.7–v0.9）

日期：2026-10-15
基线：release v0.6.3（Android 补丁版，编辑功能集与 v0.6.0 四端一致）
对标对象：国内主流修图/胶片类应用（醒图、美图秀秀、泼辣修图、FIMO/Dazz 一类胶片相机应用、Lightroom 移动版）的通用能力集

---

## 1. 背景与目标

v0.6.3 的编辑器已具备专业 RAW 显影主干：14 款大师配方、8 通道 HSL、小波降噪、
暗角/颗粒、批量导出与每张照片编辑记忆。与国内同类应用对照后，缺口集中在三类：

1. **专业编辑器标配缺失**：裁剪/旋转/水平矫正、多点色调曲线、白平衡吸管、撤销/重做栈。
2. **国内流行交互缺失**：长按看原图对比、社交比例裁剪预设、配方/滤镜导入导出与分享、
   胶片日期水印（FIMO/Dazz 类应用的标志性功能）。
3. **进阶调色能力缺失**：色彩分级（阴影/中间调/高光分色轮）、局部调整（径向/线性渐变）。

目标：在不偏离"专业 RAW 显影 + 胶片模拟"定位的前提下，按 P0/P1/P2 分三期补齐，
每期保持 macOS / iOS / Android / Windows 四端行为一致。

## 2. 对标结论

国内同类应用的编辑模块普遍包含以下能力（按通用能力描述，非逐款引用）：

| 能力 | 国内同类普遍程度 | RawLab v0.6.3 现状 | 缺口判定 |
|---|---|---|---|
| 滤镜/配方 + 强度 | 标配 | 已有（16 模块之 1、2） | 无 |
| 一键自动增强/曝光 | 标配 | 已有（一键自动曝光） | 无 |
| 高光/阴影/对比/饱和 | 标配 | 已有 | 无 |
| 多点曲线 + RGB 通道曲线 | 泼辣/LR 类标配 | 仅单值 S 曲线 | 缺 |
| 裁剪/旋转/翻转/水平矫正 | 全部标配 | 无 | 缺 |
| 社交比例预设（1:1、3:4、9:16 等） | 标配 | 无 | 缺 |
| 白平衡吸管（灰点取样） | LR 类标配 | 仅色温/色调滑杆 | 缺 |
| 长按对比原图 | 移动端标配 | 无 | 缺 |
| 撤销/重做/编辑历史 | Snapseed"查看修改内容"类标配 | 仅整体重置，无历史栈 [Assumption, TBD] | 缺 |
| 色彩分级（三色轮） | LR/达芬奇风标配 | 无 | 缺 |
| 局部调整（径向/线性渐变、画笔） | 泼辣/LR 类标配 | 无 | 缺 |
| 配方导入导出/分享 | 醒图模板、LR 预设导出 | 仅支持自定义 Look 本机管理 | 缺 |
| 胶片日期水印/边框 | FIMO/Dazz 类标配 | 无 | 缺 |
| 批量套配方一键导出 | 标配 | 批量导出已有，需与配方联动确认 [Assumption, TBD] | 部分 |
| AI 降噪/AI 蒙版（主体、天空） | 新趋势 | 传统小波降噪已有 | 远期 |
| 美颜/瘦脸/贴纸/拼图/社区 | 醒图类标配 | 无 | **不做**（偏离 RAW 定位） |

## 3. 范围

- 入口条件：用户在任一客户端打开一张 RAW 照片进入编辑器。
- P0：补齐专业编辑器标配，使"导入 → 调整 → 裁剪 → 对比 → 导出"闭环不劣于国内同类。
- P1：对齐国内流行能力（色彩分级、局部渐变、配方分享、日期水印、社交比例）。
- P2：差异化与生态（AI 降噪、AI 蒙版、模板广场）。
- 明确不做：人像美颜瘦脸、贴纸、拼图、图文排版、社区信息流。这些与 RAW 专业显影
  定位冲突，且维护成本高；若后续用户数据支持再另行立项。

## 5. 新增模块功能需求

### FR-01 裁剪与几何矫正（P0）

| 项 | 内容 |
|---|---|
| 触发 | 编辑器工具栏进入"裁剪"模式 |
| 行为 | 自由拖拽裁剪框；旋转 ±45° 细步进；水平线矫正（沿画面直线划线自动摆正）；九宫格辅助线 |
| 比例预设 | 自由、原比例、1:1、4:3、3:4、16:9、9:16、3:2、2:3（9:16/3:4 面向小红书/朋友圈发布） |
| 规则 | 裁剪仅作用于输出与预览取景，不写入原始文件；旋转角度与裁剪框随编辑记忆持久化 |
| 状态 | 裁剪后调节直方图按裁剪区域重算；"重置"单独提供"重置裁剪" |
| 例外 | EXIF 旋转方向优先；极小裁剪框（小于画面 5%）拒绝确认 |

### FR-02 多点色调曲线（P0）

| 项 | 内容 |
|---|---|
| 触发 | 调整面板"S 曲线"模块升级后的曲线编辑入口 |
| 行为 | 亮度主曲线 + R/G/B 三条通道曲线；点击加点、拖动改形、双击删点；提供"中对比/强对比/胶片 S 曲线"预设 |
| 规则 | 保留单值 S 曲线作为旧行为兼容：旧编辑记忆读入后映射为主曲线单控制点；所有客户端同参数同结果 |
| 状态 | 曲线随编辑记忆与批量快照冻结；配方套用不覆盖用户曲线（沿用"配方只覆盖指定项"的现有规则） |
| 例外 | 控制点数上限 10 点/条；端点不可删除 |

### FR-03 白平衡吸管（P0）

| 项 | 内容 |
|---|---|
| 触发 | 色温模块新增吸管按钮后，在照片上点选中性灰点 |
| 行为 | 取样点 5×5 区域求均值，反解色温/色调写入现有 temperature/tint，自动切到"自定义"白平衡模式 |
| 规则 | 取样基于当前显影结果；连续点选以最后一次为准；吸管可 Esc 取消 |
| 例外 | 取样区命中高光裁切（≥98% 亮度）或近纯色时提示"请选择中性灰区域"且不改动 |

### FR-04 撤销/重做与编辑历史（P0）

| 项 | 内容 |
|---|---|
| 触发 | 任意调节操作提交后自动入栈；工具栏撤销/重做按钮；移动端双指点击撤销（各端一致的手势可后续统一） |
| 行为 | 步级撤销/重做；"查看修改内容"列表（对齐 Snapseed 交互习惯），列表项可点击回退到该步或删除该步 |
| 规则 | 栈深上限 50 步；裁剪、白平衡、曲线、HSL、效果均入栈；切换照片清空当前栈（编辑记忆仍按照片保存） |
| 状态 | 栈不持久化，重开 App 后从编辑记忆恢复最终态、栈为空 |
| 例外 | 批量任务运行中禁用历史回退，提示"批量进行中" |

### FR-05 对比原图（P0）

| 项 | 内容 |
|---|---|
| 触发 | 长按照片区域（移动端）/ 按住对比按钮或快捷键（桌面端） |
| 行为 | 按住期间显示无调节的原片（含裁剪取景，便于对位）；松开恢复当前编辑态 |
| 规则 | 对比时叠加"原图"角标；录屏/截屏场景下角标同样存在 |
| 例外 | 无 RAW 显影缓存时首次按住需等待首帧，显示加载态 |

### FR-06 强度对比指示（P1）

强度滑杆拖动时，画面左右分屏显示"原片 | 当前强度"，松手恢复整幅当前态。
分屏位置默认居中，可拖动。依赖 FR-05 的原片渲染通路。

### FR-07 色彩分级（P1）

| 项 | 内容 |
|---|---|
| 触发 | 调整面板新增"分级"模块 |
| 行为 | 阴影/中间调/高光三组色轮 + 强度滑杆；另提供整体"饱和度微调"轮（对齐 LR 的三轮+全局结构） |
| 规则 | 作用顺序置于 HSL 之后、暗角/颗粒之前（见第 6 节管线）；色轮以色相角 + 强度两参数描述，四端复用同一核心实现 |
| 状态 | 三组参数独立持久化进编辑记忆；旧记录默认全部归零（沿用"旧记录默认关"惯例） |
| 例外 | 强度为 0 时不进入渲染路径，避免无谓 GPU 开销 |

### FR-08 配方/Look 导入导出（P1）

| 项 | 内容 |
|---|---|
| 触发 | Look 管理菜单新增"导出配置"；首页/相册页新增"导入配方" |
| 行为 | 导出为 `.rawlab-look` 文件（JSON：配方参数 + HSL + 曲线 + 分级 + 效果 + 强度默认值），支持生成二维码；导入扫码或选文件 |
| 规则 | 与现有第三方 `.cube` LUT 导入并存：`.cube` 走 LUT 通路，`.rawlab-look` 走参数通路；导入重名时让用户选择"替换/另存" |
| 状态 | 导入成功后出现在 Look 库，命名规则与现有自定义 Look 一致 |
| 例外 | 文件损坏/版本不识别时明确报错并不改库；二维码包含参数超出 v0.7 字段时按版本号拒绝 |

### FR-09 胶片日期水印与边框（P1）

| 项 | 内容 |
|---|---|
| 触发 | 效果组新增"水印"模块；导出确认页可开关 |
| 行为 | 经典胶片日期戳（橙字等字体样式 3–4 款）与细边框；时间取 EXIF 拍摄时间，无 EXIF 时取文件修改时间 |
| 规则 | 水印仅作用于导出结果，编辑预览默认显示（可关）；位置固定下右，字号随导出尺寸等比缩放 |
| 状态 | 水印参数进编辑记忆；批量导出统一按各照片参数渲染 |
| 例外 | 拒绝写入任何原文件（只影响导出物），与"保留原片"的产品原则一致 |

### FR-10 AI 降噪（P2，预研）

在小波降噪之外提供基于学习模型的降噪档位。移动端受峰值内存约束（历史版本已有
移动端内存边界结论，见 v0.4.x 发布说明），先做桌面端验证再评估移动端可行性。
不承诺时间点，进入 P2 仅立项预研。

### FR-11 AI 蒙版与局部调整（P2）

P1 先交付"径向渐变 + 线性渐变"两个几何局部工具（对齐泼辣/LR 的入门局部能力），
作用对象为曝光/对比/色温/饱和/分级五类参数；AI 主体/天空识别蒙版在 P2 评估。
几何渐变蒙版的技术路径（CPU + Metal/GLES/D3D11 四后端）与 FR-07 同批设计。

## 6. 共享规则

### 6.1 调整管线顺序（新增模块插入点）

现管线（曝光 → 白平衡 → 高光/阴影/对比 → S 曲线 → 饱和 → HSL → 降噪/锐化 → 暗角/颗粒）
中插入：

```
… → HSL → 色彩分级(FR-07) → 局部蒙版(FR-11) → 降噪/锐化 → 暗角/颗粒 → 水印(仅导出, FR-09)
```

裁剪/旋转（FR-01）在几何域最先应用；多点曲线（FR-02）替换 S 曲线节点位置。

### 6.2 四端一致性

- 所有新参数进 `RawSettings`/`EditSettings` 等共享模型，核心计算收敛在共享显影核心
  （lutools/sony2fuji），CPU、Metal、GLES、D3D11 四后端同参数同结果，沿用 0.6.0
  "HSL 灰部渐变一致"的验证方式（跨后端回归对比）。
- 新模块默认关闭旧记录兼容开关：旧编辑记忆/批量快照读入后新参数取默认值，行为不变。

### 6.3 编辑记忆与批量

- 每张照片的编辑记忆扩展字段（裁剪、曲线点、分级、水印等）向后兼容读入。
- 批量任务继续冻结参数快照；"套用当前设置到文件夹"包含新模块参数。

## 7. 版本节奏建议

| 版本 | 内容 | 对应需求 |
|---|---|---|
| v0.7.0 | 裁剪几何、多点曲线、白平衡吸管、撤销/历史、对比原图 | FR-01~05 |
| v0.8.0 | 色彩分级、径向/线性渐变、配方导入导出、日期水印、社交比例预设、强度对比 | FR-06~09、FR-11 前半 |
| v0.9+ | AI 降噪预研、AI 蒙版评估、目标调整、颗粒尺寸档位 | FR-10、FR-11 后半 |

## 8. 开放问题（TBD）

1. 撤销/重做是否已有未纳入本清单的实现（文件清单未见历史栈模块，按"缺"规划，需代码确认）。
2. 批量导出与配方联动的现状（"应用当前设置到文件夹"是否含配方强度覆盖规则），影响 FR-08 的导出字段。
3. 二维码配方的容量与容错策略（参数超限时自动转文件分享还是压缩字段）。
4. `.rawlab-look` 文件格式是否需要与 `.cube` LUT 互相打包（一个 Look 同时携带参数与 LUT 引用）。

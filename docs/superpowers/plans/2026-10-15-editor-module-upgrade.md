状态：v2.0 完整规格版（2026-10-15 重建）

## 2. 全局设计约定

### 2.1 四端一致性
macOS / iOS / Android / Windows 同参数同结果。所有像素级计算收敛在 lutools C++ 共享引擎；四端只做参数建模、持久化与 UI。语义一致、存储基点独立（如 iOS 对比度 1±1、Android 0±1 为既有差异，跨端不直接迁移数值）。

### 2.2 编辑记忆 schema 版本化迁移
- 新增字段：旧记录缺字段时取默认值（crop=nil、curve=nil、schemaVersion 缺省=1）。
- 被替代字段：单值 `toneCurve`（S 曲线）与多点 `curve` 并存两个版本，防旧版本回滚丢失。
- v0.7.0 写入 `schemaVersion = 2`；缺省视为 1（v0.6.3 基线）。

### 2.3 渲染管线节点顺序
几何域（裁剪/旋转）→ 显影域（WB/曝光/高光阴影/S 曲线/多点曲线/对比/饱和）→ 细节域（降噪/锐化）→ 效果域（暗角/颗粒/HSL）→ 输出域（色彩空间/缩放/格式）。
v0.7.0 落地顺序：多点曲线接入显影域（S 曲线之后）；裁剪先落几何域存储与导出参数，实时预览裁剪框四端 UI 分任务实现。

## 3. 数据模型与持久化（T1）

### 3.1 字段定义（四端一致）

| 字段 | 类型 | 默认 | 约束 |
|---|---|---|---|
| `schemaVersion` | Int | 1（缺省） | v0.7.0 写 2 |
| `crop` | CropSettings? | nil | 见 3.2 |
| `curve` | CurveSettings? | nil | 见 3.3 |

### 3.2 CropSettings（FR-01 数据模型）

| 字段 | 类型 | 约束 |
|---|---|---|
| `aspect` | String | `original` / `free` / `1:1` / `4:3` / `3:4` / `3:2` / `2:3` / `16:9` / `9:16` |
| `x`,`y` | Double | 归一化裁剪框左上角，[0,1] |
| `w`,`h` | Double | 归一化宽高，(0,1]，x+w ≤ 1，y+h ≤ 1 |
| `angle` | Double | 水平校正角度 [-45,45]，度；透视校正后续版本 |

校验失败 → 整体丢弃 crop（回退 nil），不抛出阻断。

### 3.3 CurveSettings（FR-02 数据模型）

| 字段 | 类型 | 约束 |
|---|---|---|
| `points` | [CurvePoint] | 2...64 个；每个 {x: [0,1], y: [0,1]}；x 严格递增 |
| 恒等 | - | [(0,0),(1,1)] 等价 nil，不存储不发送 |

插值：Fritsch–Carlson 单调三次 Hermite（无过冲伪影）；定义域外钳制端点值。
兼容：渲染先应用单值 S 曲线（`toneCurve`），后应用多点曲线；`curve == nil` 时管线行为与 v0.6.3 逐位一致。

### 3.4 各端持久化承载

| 平台 | 载体 | 迁移方式 |
|---|---|---|
| iOS | `RawSettings` Codable JSON | `decodeIfPresent` 缺省 nil；encode 写 schemaVersion=2 |
| macOS | `Adjustments` Codable JSON | 同上 |
| Android | `edits.properties`（EditStore） | 新增独立 key `record.<id>.crop` / `.curve` / `.schema`；缺 key 走默认 |
| Windows | `edits.json`（AdjustmentSnapshot） | Snapshot 增加可选参数（Crop/Curve/SchemaVersion），旧 JSON 缺字段默认 null |

## 4. 功能需求规格

### FR-01 裁剪与几何
- 裁剪框按归一化矩形存储，宽高比预设锁定（见 3.2）。
- 导出/最终渲染按裁剪矩形取景；预览四端 UI 显示裁剪框与三分网格。
- angle 仅做水平旋转校正，输出尺寸取内接矩形。
- 重置"几何"组 = 清空 crop。
- 验收：含 crop 的编辑记录在四端导出同几何结果（同参数同裁剪）。

### FR-02 多点色调曲线
- 曲线编辑器：添加/拖动/删除锚点（≤64），双击删除（移动端长按删除）。
- 引擎保证单调不产生过冲；x 严格递增校验失败拒绝保存。
- 与单值 S 曲线叠加次序固定（先 S 曲线后多点曲线），次序不随版本变化。
- 曲线作用于 RGB 主明度（分通道应用），v0.7.0 不提供分通道曲线。
- CPU 渲染路径必现；GPU 路径未加速前 Auto 回落 CPU，Force 返回 PROCESSING_ERROR（不静默丢弃）。

### FR-03 白平衡吸管
- 预览图上取样中性灰点 → 换算色温/色调写入自定义白平衡。
- 取样像素为 RAW 线性域（复用 `sony2fuji_session_get_raw_white_balance` 的标定思路），四端同点同结果。
- 吸管结果进入撤销栈（FR-04）。

### FR-04 撤销/重做
- 字段级增量命令栈，上限 50 步；滑杆拖动合并为单步（拖动结束提交）；配方套用为单步；吸管取样为单步。
- 跨端快捷键：macOS/Windows ⌘Z/⌘⇧Z、Ctrl+Z/Ctrl+Y；移动端提供撤销按钮。
- 栈不持久化（会话内有效），编辑记忆本身不受影响。

### FR-05 对比原图
- 长按（移动端）/按住 C（桌面端）显示原始未编辑图；松开恢复。
- 对比不改变编辑状态、不进入撤销栈。
- 原图基准 = 当前曝光模式解码后的显影基准（非 RAW 传感器数据），与 v0.6.3 首次打开视图一致。

## What's New

- Decode supported JPEG XL-compressed DNG data through Adobe DNG SDK 1.7.1,
  retaining the shared LibRaw decoder and its existing camera support.
- Export processed images as rendered, float32 DNG files, alongside JPEG and
  16-bit PNG. These files contain rendered pixels, not the original sensor
  mosaic or an editable copy of the source RAW.
- Use English, Simplified Chinese, German, French, Japanese and Spanish on
  all four clients, including Lens and DNG controls and dynamic states.
  Switching language preserves editing settings and frozen batch jobs.
- Apply Lensfun profile-based correction and auto-crop, with manual profile
  selection, persistent settings and metadata for the applied correction.
- Render previews for the current viewport and reuse denoise analysis with
  cache keys that account for Lens settings, crop and exposure baseline.
  FINAL exports use independent full-quality rendering.

The inherited recipes, HSL, effects, local edit memory and batch export remain
available. GPU Auto retains CPU fallback; Force requires actual backend
execution. A GPU-capable package alone does not establish hardware coverage.

## Verification and Limits

Final combined results belong in [the integration tracker](../verification-v0.7.0.md).
Original feature reports retain their source, configuration and platform scope.

- Android Sony 7008x4672 rendered-DNG attempts were terminated by emulator
  guest `lmkd` under low swap. The smaller DJI fixture passed; that result does
  not establish Sony native-size DNG or physical-device coverage.
- iOS six-language Lens/DNG state and actual Files Save passed. Native Files
  cancellation remains unverified.
- The localization follow-up's Windows export check used GPU OFF. Earlier
  native D3D11 evidence retains its original source and configuration.
- Physical mobile devices, larger RAWs, Android/macOS x86_64 runtime and
  untested OS versions remain outside the recorded coverage. Windows
  SaveFileDialog/Explorer interaction is not certified.
- Existing iOS RAW-to-raster Lens-panel state and the model-level DNG
  preview/busy guard observations remain documented; normal UI export has
  preview/busy gating. They were not silently redesigned by localization.
- Local results are not GitHub CI results. Empty checks do not establish a
  passing or running CI workflow.
